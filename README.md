# 🎮 Jokenpô - Pedra, Papel e Tesoura

## 📌 Sobre o projeto

Este projeto consiste em um jogo de Jokenpô,
desenvolvido utilizando a linguagem html.

O jogador escolhe entre Pedra, Papel ou Tesoura
e disputa uma partida contra o computador.

## 🚀 Funcionalidades

- Escolha entre Pedra, Papel e Tesoura.
- Escolha aleatória do computador.
- Identificação do vencedor.
- Exibição do resultado da partida.
- Interação com o usuário.

## 🛠️ Tecnologias utilizadas

- Python 3
- Biblioteca Random

## ▶️ Como executar

1. Instale o Python 3.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto.
4. Execute o arquivo jokenpo.py.

## 🎯 Objetivo

Projeto desenvolvido para praticar lógica
de programação, estruturas condicionais,
entrada de dados e geração de valores aleatórios.
